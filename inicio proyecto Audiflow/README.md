# 🌐 Inicio Proyecto Audiflow — Interfaz Web, HTML, CSS & JavaScript

Este directorio contiene la totalidad de la **interfaz de usuario (Frontend), páginas HTML de inicio y aterrizaje, estilos CSS y scripts JavaScript del cliente** para AuditFlow AI.

---

## 📂 Contenido del Directorio

### 1. 📄 Páginas HTML Principales
* **`index.html`:** Página de inicio principal de la aplicación con selector de postura de 3 vías, zona de carga OCR, panel de resultados, escudo de omisiones y modales de venta (CFO y Cotización Proforma B2B).
* **`admin.html`:** Panel de administración fiduciario con control de leads, métricas y panel de 10 clientes hoy.
* **`video.html`:** Reproductor del video comercial interactivo de 40s con selector de audio multilingüe.
* **`alternativas-docusign.html`:** Landing page SEM comparativa frente a DocuSign CLM e Ironclad.
* **`auditar-contrato-arrendamiento.html`:** Landing vertical para arrendamientos comerciales.
* **`auditar-contrato-servicios-it.html`:** Landing vertical para contratos IT y SaaS.
* **`auditar-factura-proveedor.html`:** Landing vertical para facturas B2B.
* **`privacy.html`:** Política de privacidad fiduciaria y cumplimiento GDPR Art. 28 / SOC-2.
* **`terms.html`:** Términos de servicio y garantía 10x ROI.

### 2. 🎨 Estilos & Diseño (CSS)
* **`css/styles.css`:** Hojas de estilo personalizadas, animaciones de escaneo láser y Tailwind Dark Mode.

### 3. ⚡ Scripts del Cliente (JavaScript)
* **`js/app.js`:** Controlador principal de la aplicación cliente (gestión de estado, OCR, renderizado de hallazgos, fallbacks, memorando CFO y proformas).
* **`js/i18n.js`:** Motor de internacionalización multilingüe (Español, Inglés, Alemán).
* **`js/payment.js`:** Manejador de pasarelas de pago (Stripe, Lightning Strike, Wompi).

### 4. 🖼️ Multimedia & Recursos
* **`images/`:** Gráficos, redlines visuales y carruseles.
* **`assets/`:** Favicon y capturas de demostración.
* **`audio/`:** Pistas de audio neuronal multilingüe para el video comercial (ES, EN, DE, FR).
