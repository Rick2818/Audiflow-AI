# 💼 Ventas Audiflow — Centro Maestro de Campañas y Cierres B2B

Bienvenido al repositorio central de **Ventas Audiflow**. Aquí se concentran todas las **campañas activas de prospección, outbound, bases de datos fiduciarias, scripts de despacho automatizado y estrategias de conversión**.

---

## 📂 Organización de las Campañas

### 1. 👥 Bases de Datos de Leads & Decisores (`Bases_de_Datos_Leads/`)
* **`CFOS_EL_SALVADOR_Y_GUATEMALA_250.csv`:** Base de 250 Directores Financieros (CFOs) de Centroamérica.
* **`DIRECTORES_LEGALES_250_WAALAXY.csv`:** Base de 250 Socios y Directores Jurídicos lista para Waalaxy.
* **`MENSAJES_PROSPECCION_LINKEDIN_LISTOS.csv`:** Base masiva con mensajes personalizados pre-redactados.
* **`PROSPECCION_LINKEDIN_DASHBOARD.html`:** Tablero visual interactivo para seguimiento del embudo.

### 2. ⚡ Scripts de Despacho Automatizado (`Scripts_Despacho_Campanas/`)
* **`dispatch_cfos_sv_gt_campaign.js`:** Despacho autónomo de correos para campaña de CFOs con Memorando de ROI.
* **`dispatch_nordicos_campaign.js`:** Despacho para decisores de Suecia, Noruega, Dinamarca y Finlandia.
* **`load_and_dispatch_250_leads.js`:** Ejecutor de cadencias de prospección fiduciaria.

### 3. 📖 Playbooks & Cierres Rápidos (`Playbooks_y_Estrategias_Campanas/`)
* **`PLAYBOOK_OUTBOUND_14_DIAS_LINKEDIN.md`:** Secuencia de 3 pasos (Apertura, Escudo de Omisiones + Memo CFO, Cierre WhatsApp VIP).
* **`KIT_CIERRE_RELAMPAGO_10_CLIENTES_HOY.md`:** Protocolo Fast-Track 24h para captar los primeros 10 clientes.
* **`PLAN_DE_CHOQUE_4_ACCIONES_HOY.md`:** 4 acciones comerciales prioritarias por jornada.
* **`AuditFlow_AI_Sales_and_n8n_Master_Plan.pdf`:** Arquitectura de ventas y flujos automáticos en n8n.

### 4. 📢 Campañas de Pauta Digital (`Pauta_Google_y_Meta_Ads/`)
* **`ESTRATEGIA_SEM_GOOGLE_ADS_2026.md`:** Campaña Google Ads (Alternativas DocuSign/Ironclad, Garantía 10x ROI, Memo CFO, Proforma B2B).
* **`ESTRATEGIA_Y_ANUNCIOS_PAISES_NORDICOS_2026.md`:** Campaña Nórdica con cultura Lagom y GDPR Art. 28.
* **`PROGRAMACION_7_DIAS_META_BUSINESS_SUITE.md`:** Programación semanal de Meta Ads (Facebook & Instagram).
